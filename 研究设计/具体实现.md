

## 一、为什么 ActiveVLN 是更好的基座(先纠正一个我之前的疏漏)

我之前论证方向 A 时说过"VLN-CE 纯 RGB 设置下没有特权坐标,所以几何奖励用不了"——**这个说法需要修正**。ActiveVLN 的 soft success reward 恰恰用到了 Habitat 仿真器提供的测地距离:

$$R = 15 \cdot \mathbb{I}(\text{success}) \cdot \frac{d_{goal}}{3}$$

这里 $d_{goal}$ 就是通过仿真器 API 拿到的特权信息,只是**它只用来算训练时的奖励,不作为策略的输入**(策略仍然只看 RGB)。这和 SRGPO 用 AI2-THOR 引擎坐标算 VPR 本质是同一件事——只是 ActiveVLN 目前只在**轨迹终点**用了一次,没有做成逐 step 的过程奖励。

这个修正对你反而是好事,因为它带来一个更扎实的问题定义:

> **ActiveVLN 已经证明了"利用仿真器特权信息计算奖励"在 VLN-CE 是被社区接受的做法,那么为什么不把它做成逐 step 的过程奖励?**

不再需要论证"VLN-CE 没有几何信息可用"这种站不住脚的前提,而是直接问"现有工作为什么只在终点用一次距离信号"。

## 二、更关键的发现:ActiveVLN 的 GRPO 本质上没有做任何 step-level credit assignment

仔细看 ActiveVLN 的 Eq.(7):

$$L_{RL} = \mathbb{E}\left[\frac{1}{G}\sum_i \frac{1}{|o_i|}\sum_t \min(\rho_{i,t} A_{i,t}, \text{clip}(\rho_{i,t})A_{i,t})\right]$$

这里的 $A_{i,t}$ 实际上**对同一条轨迹内所有 step 都是同一个标量**(轨迹级 outcome advantage 广播到每个 token/action)——也就是说,一条 50 步的轨迹里,不管第 3 步走对了、第 30 步走错了,每一步拿到的 advantage 完全一样。这正是 SACA 和 SRGPO 都在解决的问题(sparse reward → 无法区分步内好坏),但 ActiveVLN 这篇 2025.9 的工作**完全没碰这个问题**,它的创新点全部集中在"如何让 agent 主动探索"和"如何提升 rollout 效率"上。

这给了你一个非常干净、有说服力、面向最新真实 baseline 的研究缺口陈述:

> "即使是最新的 VLN-CE 主动探索式 RL 框架(ActiveVLN),其 GRPO 目标仍然只利用轨迹级稀疏结果奖励,组内每条轨迹内部的所有动作共享同一个优势值,没有任何 step 级别的信用分配机制。本文在此框架上引入过程奖励,验证密集监督能否与主动探索(而非模仿式路径匹配)相兼容。"

这比之前"缝合 SACA+SRGPO"的故事扎实得多,因为你现在是**在一个已发表、有完整代码规划、有强 baseline 数字的框架上做增量式、有明确消融对照的改进**,答辩时非常好讲。

## 三、必须正面处理的坑:ActiveVLN 自己的负面结果(Table III)

这是最重要的一点,你**不能忽略**。ActiveVLN 做过 path alignment reward 的消融:

$$R_{align} = w_{succ}\cdot\mathbb{I}(\text{success})\cdot\frac{d_{goal}}{3} + w_{nDTW}\cdot\text{nDTW}$$

结果是:**加了 nDTW(轨迹与专家路径的形状相似度)之后 SR 反而下降**,权重越高降得越多。论文的解释是:nDTW 本质上是在奖励"和专家路径长得像",这会**惩罚 agent 探索出的、虽然路线不同但同样能到达目标的合法路径**,与 Stage 2 的"active exploration"设计哲学直接冲突。

如果你直接把 SACA 式的语义过程奖励(本质上也是"agent 是否在按 landmark 序列走")套进去,**审稿人第一反应会是"这和 nDTW 有什么本质区别,会不会重蹈覆辙"**。所以你必须在方法设计和实验里明确回应这一点,而不能假装没看到。

**关键区分点需要在论文里讲清楚**:nDTW 惩罚的是"路径形状偏离专家轨迹",是一种**几何相似度**约束,不管 agent 有没有按指令语义走对,只要形状不像专家路径就扣分;而你提出的 landmark 进度奖励惩罚的是"是否按照指令描述的语义顺序推进"(先经过 A 再经过 B),**允许在两个 landmark 之间走任意路线**,只要最终按序完成关键节点即可——这是"语义顺序对齐"而不是"轨迹形状对齐"。两者理论上应该是不同性质的约束,但这只是假设,**必须做实验验证**,不能只靠论证。

**具体建议实验**:在你的方法里,构造一个"路线不同但 landmark 顺序正确"的合成轨迹(比如同样经过卧室门再经过床再到达目标,但具体走法和专家路径不一样),验证你的过程奖励是否给出接近满分的评价——而如果换成 nDTW,这条轨迹会因为形状不像专家而被扣分。这个对比实验直接就是你论文里最有力的一张图。

## 四、具体整合设计(基于 ActiveVLN 的结构改造)

### 4.1 保留不变的部分

- Stage 1 IL bootstrap 不变;
- Stage 2 outcome reward(soft success reward)不变,作为 episode-level advantage $A_E$ 的来源,继续用 ActiveVLN 原有的组内(同指令 G=4 条轨迹)归一化;
- Dynamic early-stopping、scene caching/preloading 全部保留,这些和奖励设计正交。

### 4.2 新增:轻量级 landmark 进度奖励(替代 SACA 的三级感知级联)

这里必须正视一个新的可行性问题:**ActiveVLN 整篇论文的第二大贡献就是训练效率优化**(dynamic early-stop、scene caching、preloading,Table V 专门量化每个技巧节省的时间)。如果你在这个基础上加一整套 CLIP+GroundingDINO+SAM3 级联(SACA 的做法),会直接违背这篇工作的核心设计哲学,rollout 时间会显著上升,这在答辩时会被抓住"你的改进是不是拿效率换来的"。

**解决方案**:不新增独立的感知模型栈,而是**复用策略模型自身**(Qwen2.5-VL-3B)做零样本语义打分:

- 指令解析成 landmark 序列 $L={l_1,...,l_m}$:这一步只需要在训练开始前对全部指令做一次性离线解析(用同一个 Qwen2.5-VL 或更小的模型做 prompt 解析),不占用 rollout 时间;
- 逐 step 的 landmark 匹配度:不用额外跑 CLIP/GroundingDINO,而是**直接用策略模型 forward pass 时已经产生的视觉-语言对齐信号**(比如让模型在生成动作 token 之前,先用一个简短的辅助 prompt/或者复用已有 hidden state 做一个轻量打分头,判断当前观测与 active landmark 的匹配程度)。因为 Qwen2.5-VL 本身就在处理这帧图像做动作决策,复用而不是新建一次 forward,边际成本很低,直接解决了"额外感知模块拖慢训练"的问题。
- 只在**动作 chunk 边界**(ActiveVLN 用了最多 3 个动作合并的 chunking)算一次过程奖励,而不是每个原始动作都算——这同时降低开销,也自然适配 ActiveVLN 的 compact action prediction 设计。

### 4.3 局部校准 + 跨样本随机分组(沿用之前的核心创新点)

对逐 chunk 的语义匹配分数做局部 z-score 校准,得到 $\tilde R_t$,使其跨指令可比。

**这里需要根据 ActiveVLN 的实际 batch 规模调整**:ActiveVLN 每个 batch 是 8 条指令 × 4 条 rollout = 32 条轨迹,比 SRGPO 论文里的规模小。要做跨指令随机 step 分组,32 条轨迹提供的 step 池子是否足够支撑稳定的组内均值/方差估计,需要专门做一次实验验证(类似 SRGPO 4.5 节对 $N_S$ 的敏感性分析),如果不够可能需要:

- 提高 batch size(如果显存/效率允许);
- 或者退化为"半随机"分组——组内既包含同指令的其他 rollout,也混入其他指令的若干 step,而不是纯随机,以保证组内既有一定的任务同质性,又不会像 SACA 那样在全失败组时坍塌。

这正好呼应了我之前建议的"退化感知自适应分组"机制,在 ActiveVLN 这个更小 batch 的场景下反而更有必要,不是可选项而是刚需。

### 4.4 最终优化目标

$$A_{i,t} = A_E(\tau_i) + \omega \cdot A_S(\tilde R_t^{(i)})$$

$A_E$ 沿用 ActiveVLN 原有 GRPO 组内 outcome advantage,$A_S$ 是新增的跨样本随机分组 step advantage,套进 ActiveVLN 原有的 PPO-clip 目标(Eq. 7)里,不需要改动其他工程组件。

## 五、需要新增的实验/消融(直接对标 ActiveVLN 已有的表格结构,方便对比)

1. **对照 Table III**:在"soft success only / hard success / path-align(nDTW) / 本文语义进度奖励"四者之间做同样的消融,证明你的方法不会重蹈 nDTW 的覆辙(SR 不降反升)——这是必须做、也是最关键的一张表。
2. **对照 Table IV**(multi-turn vs single-turn):验证你的 step reward 是否和 multi-turn paradigm 同样兼容甚至互相增强,因为 ActiveVLN 自己发现 multi-turn 对 RL 增益远大于 single-turn,如果你的密集奖励能进一步放大这个增益,是很有力的证据。
3. **对照 Table V**(效率消融):加入你的语义打分模块后的 rollout 时间对比,证明复用策略模型而非新增感知栈确实没有显著拖慢训练——这是回应"效率哲学冲突"质疑的直接证据。
4. **landmark 顺序合规性实验**(4.3 提到的合成对照轨迹实验),直接反驳"这和 nDTW 一样会惩罚路径多样性"的质疑。
5. **跨指令分组的 batch 规模敏感性分析**,回应"32 条轨迹够不够做随机分组"的可行性质疑。

## 六、小结

这个整合是可行的,而且比之前"SACA+SRGPO 缝合"的版本故事更扎实,原因是:ActiveVLN 提供了一个**真实、最新、已发表、有开源代码规划**的 VLN-CE 主动探索 RL 系统,该系统明确暴露了"零 step-level credit assignment"这个缺口,同时又提供了一个**现成的负面对照实验(nDTW)**,逼着你必须在方法设计上做出真正的区分(语义顺序对齐 vs 路径形状匹配),而不是空泛地说"密集监督更好"。你的核心贡献变成三层:(1)复用策略模型而非额外感知栈的轻量语义进度奖励,直接回应 ActiveVLN 的效率哲学;(2)局部校准使其可跨样本比较,支持随机分组;(3)用合成对照实验证明该奖励与主动探索兼容,不同于已被证伪的 nDTW 路径匹配奖励。这条线的实验对照表几乎可以直接复用 ActiveVLN 论文的表格结构,写作和答辩时的说服力会强很多。
