	- 应用层，负责向用户提供一组应用程序，比如 HTTP、DNS、FTP 等;
	- 传输层，负责端到端的通信，比如 TCP、UDP 等；
	- 网络层，负责网络包的封装、分片、路由、转发，比如 IP、ICMP 等；
	- 网络接口层，负责网络包在物理网络中的传输，比如网络包的封帧、MAC寻址、差错检测，以及通过网卡传输网络帧等；
### 键入网址到网页显示
1. 浏览器解析URL并生成HTTP消息
2. 客户端向本地DNS（通常由网络运营商自动分配）请求目标服务器的IP地址，当然如果本地有缓存可以直接查到
3. 拿到 IP 地址后，浏览器与服务器之间通过 **三次握手** 建立 TCP 连接。三次握手目的是**双方都保证双方都有发送和接收的能力**，一条 TCP 连接建立后，可以在上面连续发送多个 HTTP 请求。
4. 传输过程：路由器逐跳转发，知道下一站的 IP 地址之后（这一IP不会记录），接下来需要通过**ARP**协议根据 IP 地址查询 MAC 地址，并将查询的结果作为接收方 MAC 地址（ARP协议只在同一局域网内发送广播请求）。转发过程中目标IP地址作为最终目的地始终不变，每次转发MAC 头部都会被丢弃重装，（MAC 头部的作用就是将包送达路由器，其中的接收方 MAC 地址就是路由器端口的 MAC 地址）

## 应用层
- http协议：HTTP 是一个在计算机世界里专门在「两点」之间「传输」文字、图片、音频、视频等「超文本」数据的「约定和规范」。

- GET：从服务器获取指定资源
- POST：根据请求负荷对指定资源做出处理
