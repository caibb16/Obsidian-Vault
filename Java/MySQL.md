## 查询
### 基础查询
增删改查：insert/delete/update/select
### 多表查询
1. 内连接：$A\cap B$
2. 外连接：$A + A \cap B$
3. 自连接：将一张表看作两张表，A as a, b，语法与内连接、外连接相同
## 索引
索引的定义就是帮助存储引擎快速获取数据的一种数据结构，形象的说就是**索引是数据的目录**
### 数据存储
InnoDB 的数据是按「数据页」为单位来读写的，数据页大小默认为16KB，也就是说数据库每次至少读取16KB的内容到内存中，数据页中的记录按照「主键」顺序组成单向链表。
### B+树查询
InnoDB中的B+树结构如下：
![[Pasted image 20260714113251.png]]
只有叶子节点存放数据，非叶子节点仅存放目录项作为索引。定位记录时，通过二分法快速定位到包含该记录的页，之后在该页内进行二分法快速定位记录到所在的分组，最后在分组内进行遍历查找。
### 聚簇索引和二级索引
- 聚簇索引：叶子结点存放实际数据（数据行），只能有一个
- 二级索引：叶子结点存放主键值
